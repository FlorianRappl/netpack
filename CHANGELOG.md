# Changelog

All notable changes to **netpack** are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project aims to
follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

> Version entries below are generated by the release pipeline from each GitHub
> release's notes (see `.github/workflows/publish.yml`); they are not edited by
> hand. The `[Unreleased]` section is a scratch space for notes before the next
> release.

## [Unreleased]

### Added

- `browser` package.json field object-map on the web platform: remap a bare
  specifier or a relative file to a browser build, or stub it with `false`.
- Constant-folding of `require()` / `import()` specifiers — string-literal
  concatenation, no-substitution template literals, and parenthesized forms are now
  resolved and bundled instead of left dynamic.
- Context imports: an interpolated dynamic `import()` (and the synchronous
  `require()` form) with a static prefix and suffix expands to one lazy chunk — or
  inlined module — per matching file, globbed recursively.
- Node/Deno fallback to the runtime's real `require` for a genuinely dynamic
  `require()` that wasn't bundled — ambient `require` for CommonJS output, a
  `createRequire(import.meta.url)` for ESM.
- Browser `__dirname` / `__filename` definitions on the web platform (per module).
- First-party, dependency-free browser polyfill shims for `path`, `process`,
  `events`, and `querystring`, plus a `node-polyfills` preset that aliases those
  builtins to them.
- Test harnesses: a real-npm bundling corpus (`corpus.sh`), Node execution tests,
  and jsdom browser-execution tests.

### Fixed

- Tree shaking: an unused re-export from a side-effect-free barrel file (e.g.
  `lucide-react`) no longer drags the whole package into the bundle — unused
  `export … from` edges are pruned and the modules behind them dropped.

## [0.8.2] — 2026-08-19

### Changed

- Improved PostCSS handling of plugins.

### Fixed

- Tree shaker handling of default exports.

## [0.8.0] — 2026-08-07

### Added

- Deterministic CSS ordering based on JS module evaluation order (#25).
- Optional build metafile JSON (artifact and dependency manifest) (#26).
- Optional license collection (#28).
- Analyzer recommendations and suggestions for bundle optimizations (#27).
- Effective third-party audits in analyzer output (#27).

### Changed

- Programmatic APIs gained build lifecycle callbacks.
- Improved documentation structure.
- Updated the used version of AngleSharp.

### Fixed

- Handling of extensionless `main` fields in packages.
- Type imports no longer taken into bundles.

## [0.7.0] — 2026-08-03

### Added

- Asset inlining with `--inline-limit` and a per-import `?inline=` modifier (#19).
- Multi-target build support via preset variants (#23).
- Split-chunks chunk grouping strategy with `cacheGroups` config (#24).
- Plugin hook system inspired by rspack (#9).
- Incremental rebuild test infrastructure (test tooling) (#22).

### Changed

- Watch mode: configurable debounce, batching, and error recovery (#20).
- Improved Node IPC reliability.
- Incremental build pipeline reworked into a 6-phase cache architecture (#21).

## [0.6.0] — 2026-07-27

### Added

- `--banner` CLI option.
- Solid.js compilation support.
- `.env` file support and `import.meta.env` replacement (#1).
- `preview` command for production builds (#4).
- `--clear-screen` flag for `--watch` / `serve` (#5).
- CSS code splitting for shared stylesheets (#7).
- Module preload directives for shared JS bundles (#8).

### Changed

- Improved error messages with source snippets (#6).
- Improved auto path for UMD modules.
- Improved npm package / exports for programmatic use from Node.js.
- Updated to AngleSharp 1.6 and AngleSharp.Css 1.0.
- Updated to .NET 10 (#2).
- Built-in Node modules are now referenced with a `node:` prefix.

## [0.5.2] — 2026-07-24

### Added

- .NET libraries published on NuGet.

### Fixed

- Version verification during npm installation.

## [0.5.1] — 2026-07-24

### Added

- Support for `exports` fields in package.json.
- Platform switch (Node.js, Deno, Web, …).
- More tests for reliability.

### Changed

- Improved Vue SFC support.
- Updated existing CLI options.

## [0.5.0] — 2026-07-21

### Added

- Svelte support.
- More output format options (CommonJS, SystemJS, UMD).

### Changed

- Improved Astro support.

## [0.4.2] — 2026-07-16

### Added

- Image variants with given dimensions or desired format.
- Essential support for Astro.

### Changed

- Improved documentation.
- Updated image processing.

## [0.4.1] — 2026-07-15

### Fixed

- Documentation links.
- npm package deployment.

### Added

- Native Federation support.
- Direct support for Preact.
- Packages for Windows ARM64 and Linux ARM64.

### Changed

- Improved Vue SFC compilation.
- Improved documentation website links.
- Updated dependencies.

## [0.3.0] — 2026-07-15

### Added

- Vue SFC support.
- Documentation website.

### Fixed

### Fixed

- Minification problems.
- JSX lowering.
